# 测试开发实习岗位雷达

公开网页：https://huayou712-maker.github.io/test-intern-radar/

发现公开招聘来源中的软件测试、测试开发、自动化测试、SDET 和 QA 实习岗位。支持搜索、城市与学历筛选、Today、Matches、Watchlist、字段变化记录和 RSS。

## 数据与判定

- 中智招聘：测试、软件测试、测试开发、自动化测试、测试实习、SDET、QA 七组关键词搜索，各关键词最多检查 400 条候选记录，取得详情并检查实习和软件测试证据。
- 国家大学生就业服务平台：实习分类下搜索同样的关键词，各关键词最多检查匿名可访问的前五页、50 条记录，取得详情并核验。
- 数据覆盖受来源搜索范围限制。单位性质使用来源明确标注；委托代招记录中的招聘服务机构性质不能代表实际用人单位。
- 招聘单位、岗位名称、地点、正文、学历、毕业年份和截止日期相同的记录合并展示，详情保留来源链接。
- 毕业年份和截止日期仅提取明确文本。未提供的信息显示“未公布”。岗位能被获取不保证仍接受投递，请在来源页面核验。
- 搜索结果未再次出现的岗位标记“待核验”；来源请求失败保留已有记录和上次成功时间。来源失败信息公开展示。
- 来源日期超过 180 天、岗位标题与实习分类冲突的记录标记“待核验”；明确超过截止日期的记录标记“已关闭”。

## 云端运行

GitHub Actions 在每小时第 17、47 分钟计划执行。GitHub 调度存在延迟，无法保证实时提醒；公开仓库长期无活动时，GitHub 可能暂停计划任务。Actions 页面可以手动运行。

GitHub Pages 提供静态网页。程序采用 Next.js 静态导出，Node.js 采集器把观察结果写入 JSON，并保留历史。公开仓库与标准 GitHub 托管运行环境可使用免费额度，无付费 API；使用需遵守平台额度与招聘来源访问规则。

网页每两分钟请求最新数据。浏览器通知需要授权并保持网页打开；后台提醒可以订阅 `/feed.xml`，由阅读器承担通知。Watchlist 仅保存于当前浏览器，提供 JSON 导入和导出。

首页公开显示检查候选数量、接入来源数量、数据文件与运行记录入口。“同步最新数据”按钮读取最近发布的数据，不会直接触发招聘来源采集。界面采用深色横向导航、暖灰背景和橙色操作按钮；桌面岗位标题 24px、详情正文 18px、辅助文字至少 14px。

## 开发与验证

需要 Node.js 24。

```sh
npm ci
npm run collect
npm run verify
npm run build
npx playwright install chromium
node scripts/verify-ui.mjs
```

验证使用采集得到的真实记录。检查数据结构、识别证据、RSS、浏览器搜索、详情、关注条件保存及移动端布局。全部来源失败时采集任务返回失败；已有有效数据可继续展示，并同步来源失败状态。

网页展示最近 200 条历史事件，RSS 提供最近 100 条；完整历史保存在 `data/state.json`。未导入任何个人认证信息，未接入账号或投递功能。
